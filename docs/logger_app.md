# ロガーアプリの使い方

アプリは **［モニター］／［制御パラメータ］／［履歴・飛行］** の3タブです。操縦・離着陸はJoyStickで行います。

**［履歴・飛行］→［保存先を指定］** でフォルダー選択画面を開き、自動・手動記録の保存先と履歴一覧を変更します。初期の保存先はプロジェクト内の`recordings/`です。**［保存先を開く］** はWindowsのファイルエクスプローラーを開きます。記録中に変更した場合、現在のファイルは元の場所に保存し、次の記録から新しいフォルダーを使います。

一覧でMATファイルを選び、**［最初の飛行］／［全記録］** を切り替えます。複数選択で最大6件を比較できます。各グラフ上に表示中のファイル名、モニターにはライブ受信元を表示します。最初の飛行の0秒は飛行制御（Mode 2）開始で、離陸完了やホバリング達成時刻ではありません。

| 表示 | 読み方 |
|---|---|
| 高度・鉛直速度 | 機体の推定、ToF斜距離・鉛直投影、ToF変化率を比較します |
| 共通推力差 | `ThrustCommand / 3.7 − BaseDuty`。高度補正の10 ms平滑化・制限後の差です |
| モーター最大−最小 | 姿勢・角速度補正による4モーターの指令差の大きさです |
| スロットル | 基準、共通推力、制限前後のモーター平均を比較します |
| 診断 | 各帯の下=OFF、上=ON、空白=未記録です。帯を跨いで値を比較しません |
| 相対XY | ○が最初の観測点、×が最後の観測点。絶対位置ではありません |
| 飛行状態 | 初期化→校正→待機→飛行制御→着陸の表示順。機体Modeは0・1・3・2・5です |

**ToF新規**の点滅はセンサーが400 Hzより遅く更新するためです。**ToF有効・推定高度・姿勢**は有効ならON、**高度制御**は実際の高度制御が有効ならONです。**スロットル飽和**のONは高出力の制限への到達を示します。状態切替の縦線には状態名を表示し、診断のON/OFF線と区別します。

以前の「P/I/PI/適用補正」では、現行モデルがP/I個別項を送信しておらず、通常パケットの補正値は0.1刻みへ丸められていました。細かな制御差が0に見えるため、現在は同じSequence・Time・BuildIDのSFIX補足を結合します。補足が欠落した時刻は空白のままです。共通推力差はPIDのP/I/D個別項ではありません。
