# horizontal-hold: 要求と動作条件

更新: 2026-10-17。状態: **実装・モデル検証済み**。[利用と実装](../../../horizontal_control.md)

## 目的・範囲

光学フローと下向きToFから水平速度を推定し、Stabilize／Auto Altitudeで中立時に相対位置を保持する。スティック操作で移動し、中立後は減速して停止位置を保持する。400 Hzの姿勢・角速度PID、離着陸Supervisor、高度制御、モーター順序を基本として使う。

既存7 PIDの内部演算・係数は維持し、その前段のRoll／Pitch目標を水平補助へ切り替える。移動中だけでなく保持中も目標とPIDの誤差入力は変わる。制御OFF時の既存出力との一致を確認し、ON時の閉ループ応答・高度への連成を別に検証する。

初期対象は平らで模様のある床、通常の室内照明、0.3～0.8 m高度。段差、反射床、無模様床、動く床、屋外の日照変化は検証範囲外。磁気の姿勢融合、絶対位置推定、自動航行は今回の範囲外。

採用方針は**移動中も水平速度を制御**する方式。目標生成を制御本体から分け、将来の自動軌道からも同じ速度目標を受け取れる境界にする。ユーザー確認によりYaw推定補正・方位保持は水平制御の後段で追加する。短い相対保持を現行Yawで検証し、実旋回と時間変化する方位誤差の影響を記録する。

## 境界信号

| 入力 | 単位・順序 | 条件 |
|---|---|---|
| FlowCounts2、FlowRaw8、FlowInfo4 | センサー2軸count、既存品質・診断、uint32時刻µs | 400 Hz。Info4(4)は取得時刻でありdtではない |
| InertialMotion | Quaternion、RawAngularRate、StaticOffsets、FilteredRate、CorrectedRate、Fresh、ReadValid | 生角速度を機体軸へ変換し、静止校正と残留バイアスを除く。Freshと読出し成功を別に判定 |
| BodyToLocalRotation、AttitudeValid | 3×3無次元、boolean | 機体→局所の回転。既存出力からの変換はPhase 0で確定 |
| BottomRange、RangeStatus、Fresh、RangeTime | m、状態、boolean、µs | 生ToFの有効性と経過時間を保持。保持された高度だけで判定しない |
| PilotSticks、ControlMode、AltitudeMode | 正規化[-1,1]、既存モード | Roll/Pitchの中心・方向は現行入力と整合させる |
| FlightMode、Run、Reset、OutputEnabled | 既存状態 | Mode 2/5かつ実行許可。Resetと低推力を優先 |
| PreviousMotorSaturation | boolean | 既存配分の飽和結果を1周期保持して返す |
| HorizontalAssistEnabled、TickTime | boolean、µs | 補助選択と共通時刻。時刻周回を処理 |

| 出力 | 単位・順序 | 用途 |
|---|---|---|
| AngleReference2 | [Roll, Pitch]、rad | 既存角度PIDへの目標。50 Hzで更新、400 Hzへ保持 |
| HorizontalMotion | PositionLocal2[m]、VelocityLocal2[m/s]、時刻・有効性 | 両軸を全区間で同じ順にする |
| HorizontalDiagnostics | 状態、解除理由、位置目標、速度目標、加速度、PI積分、制限状態 | ログ・アプリで補助状態と推定品質を確認 |

局所Xは姿勢Reset後の最初の有効観測時の機首前方、Yは右、Zは下。**地理的な北・東を意味しない**。補助有効化・復帰では同じ局所座標上の停止位置を取り直す。既存表示のEastNorthM2を入出力契約に流用しない。

## 状態と遷移

| 状態 | 目標と処理 | 遷移 |
|---|---|---|
| OFF／初期化 | 従来操縦。位置基準・PI・区間集計を初期化 | Stab＋Auto、十分な高さ、測定安定、中立で準備 |
| READY／有効化 | 現在位置を基準とし、従来角度から補助角度へ滑らかに移す | 中立ならHOLD、操作ならMOVE |
| MOVE | スティック→機体水平速度→局所速度。古い位置目標を解除 | 中立でBRAKE、故障・選択変更でOFFへ |
| BRAKE | 速度目標をゼロへ減速。位置への復帰はしない | 速度が停止閾値以下で一定時間続けば現在位置を記憶しHOLD |
| HOLD | 位置誤差P→速度目標。Yawで目標位置を回さない | 操作でMOVE、測定異常でDEGRADED |
| DEGRADED／解除 | 観測が無効になった時点でPI積分停止。補助を減らし従来操縦へ | 安定した測定＋中立でREADY。過去の位置基準は再使用しない |
| 着陸・低高度 | 有効な保持を範囲内で継続し、低高度で解除・PIリセット | 接地・待機・ResetではOFF |

着陸中に新たに補助を有効化しない。姿勢／角速度推定自体が無効、通信断、過加速度等の既存処理はSupervisorが優先する。水平センサーだけの故障で離着陸Modeの値を増やさない。

## 現行の調整パラメーター

| パラメーター | 設定値 | 根拠・調整方法 |
|---|---|---|
| 区間集計／観測・PI更新周期 | 0.0025 s／0.02 s | 同じ400 Hzタスク内で8周期ごとに完成窓を公開 |
| count/rad | 両軸385を起点 | PX4参考値。機体ごとに軸・倍率を実測 |
| 最大速度／加速度 | 0.3 m/s／0.6 m/s² | 最初の室内確認用。運動モデルと停止距離で調整 |
| 傾き上限 | 合成10° | 既存30°より小さく始め、高度・配分余裕で評価 |
| 中立ヒステリシス | 入る5%、出る8% | 中心校正後のスティック雑音で調整 |
| 高さの有効化／解除 | 0.20 m／0.15 m | PMW参考最小80～100 mmに余裕。実際のセンサー位置で校正 |
| 観測する高さの下限 | 0.08 m | 10 cmの机上静止確認にも使用。飛行補助開始は別条件 |
| 高さの上限 | 1.0 m | 最初の検証範囲0.3～0.8 mに余裕。既存表示の2 mと区別 |
| 速度平滑化時定数 | 0.05 s | 0.5 m高度で1 count/20 ms≒0.065 m/s。遅延との両立 |
| 停止判定 | 0.08 m/s未満が0.3 s | 高度依存の観測ノイズを実測して変更 |
| フロー経過時間／解除 | 25 ms／異常検出で即無効 | 区間内1点の欠測も無効。積分をリセットし0.15秒で従来操縦へ移行 |
| 距離の経過時間上限 | 150 ms | 33 ms測距＋非同期待ち。実測時刻・高度変化で条件を厳しくする |
| IMUの経過時間上限 | 7.5 ms | 読出し成功時の短い再読出しを許容。読出し失敗は即棄却 |
| 有効化・復帰の観測安定時間 | 0.5 s／1.0 s | 不安定な自動切替を防ぐ |
| 補助の立上げ／解除 | 0.3 s／0.15 s | 角度の連続性をモデル試験で確認 |
| 品質／最大傾き | SQUAL ≥25／25° | 8サンプルすべてで判定。実際の床・照明で確認 |
| 位置P／速度P・I | 0.8 /s／1.8 /s・0.5 /s² | 閉ループと条件ずれ試験の初期調整値。実機の同定値ではない |
| PI加速度／積分／加速度変化率 | 0.6 m/s²／0.25 m/s²／2 m/s³ | ベクトル制限と条件付き積分を使用 |
| 補助角の変化率 | 20°/s | 混合前の補助角を制限 |

初期区間は全サンプルの品質と時刻が成立する場合だけ観測を有効にする。部分区間を採用する緩和は、積分時間の扱いを別途検証してから行う。シャッター上限だけで無効にしない。

設定はFlowMotion・Command・VelocityPI・SelectAttitudeのダブルクリック画面から変更できる。機体ごとのフロー倍率・軸と飛行性能は、モデル試験とは別に実測して調整する。

## 受け入れ目標案

0.5 m高度・条件内で20秒の位置保持誤差を半径0.2 m以内、0.3 m/s移動から中立後1.5秒以内に0.08 m/s以下、停止までの追加移動0.25 m以内を初期目標にする。実際の位置を外部観測で評価する。数値は現時点で未達・未検証。[試験計画](horizontal-hold-test-plan.md)の結果で更新する。

## 調査に基づく確認事項

PX4では下向きフロー＋距離で速度を観測し、回転のフロー積分と角速度積分を一致させる。操縦時の移動と中立時の減速・保持はPosition Modeの参考になるが、本案は速度指令方式。参照URLと現行モデルの確認結果は[検討結果](../../../horizontal_hold_review.md)と[調査記録](horizontal-hold-review-evidence.json)に記載。
