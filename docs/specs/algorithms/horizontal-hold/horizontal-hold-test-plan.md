# horizontal-hold: 試験計画案

更新: 2026-10-17。状態: **単体・モデル・生成コード検証済み、実飛行未実施**。[要求](horizontal-hold-system.md)

座標・品質・時刻の単体確認、実ブロック4シナリオ・16評価、OFF36,000周期、簡易剛体での閉ループ4シナリオ・条件ずれ9ケース、生成MEX12,000周期の一致、アプリ13項目とログ結合を確認した。[結果一覧](../../../horizontal_control.md#検証記録)。以下は実機校正・飛行を含む全体の試験方針。機体同定値を使わない合成試験と実測結果を区別する。

## 1. 観測単体・座標校正

| 試験 | 入力・測定 | 初期の確認基準 |
|---|---|---|
| 移動方向・倍率 | 模様床から0.3／0.5／0.8 m、既知の前後・左右0.2 m移動 | 両軸と正負が一致。倍率誤差10%以内を目標、対角で軸混合を確認 |
| 純回転 | 並進を抑えたRoll／Pitch回転、正負のYaw | 回転補正後の偽速度RMS 0.05 m/s以内を目標。レバーアームと遅延を含む |
| スティック・傾き・配分符号 | 右／前操作、正負の目標角、手動の機体傾斜 | 4方向とも速度誤差を減らす角度・モーター差を作る。身体的な向きと照合 |
| 区間同期 | ランプ状角速度、0～20 msのIMU遅延、400 Hz時刻揺れ | 同じ区間のフロー／角速度／dtを使用。定数角速度だけで判断しない |
| 時刻・カウンター | uint32周回、重複、逆転、更新停止、取りこぼし | 正常な周回は継続、異常な区間は無効。巨大な移動値を生成しない |
| 品質の独立性 | valid=1＋SQUAL低、shutter変化、1～8サンプルの低品質 | validだけで採用しない。区間内の不良を最終サンプルで隠さない |
| 静止とゼロcount | 良好床で停止、motionビットの有無 | 品質と時刻が良いゼロcountは停止観測として扱える |
| ToF非同期 | 33～100 ms更新、保持、エラー、150 ms超、上昇下降 | 保持値の時刻を評価。古い距離・無効距離から正常速度を作らない |

入力はタイムスタンプ付きの固定ベクトル／テーブルへ保存し、MIL、再生、生成コード比較で同じ条件を使う。取り付けと実センサーの内在遅延は合成入力だけでは確定できない。

## 2. 制御単体MIL

| シナリオ | 条件 | 確認 |
|---|---|---|
| 中立・位置ずれ | 正負0.1 mの位置誤差、初期速度ゼロ | 目標位置へ戻す速度と加速度の符号 |
| 操作・減速・保持 | 中立→各方向／対角→中立→再操作 | MOVE中に旧位置Pが入らない。停止判定後の実位置を保持 |
| Yawと移動 | 中立で90°回転、移動中90°回転 | 位置目標は局所に固定。移動指令は機首に追従し加速度制限内 |
| Yawの実旋回と推定ずれ | ゆっくりした実旋回、一定の方位オフセット、0.1／0.5／1 deg/sの推定誤差増加 | 共通座標で速度を抑え、短時間の保持・移動誤差と成立範囲を記録。合成誤差値は実測値とは区別 |
| 中立雑音 | 中心付近±3～6%と境界往復 | ヒステリシスにより状態の細かい切替を防ぐ |
| 制限・積分 | 最大入力を5秒、傾き／モーター飽和→解除 | 上限を守り、積分が蓄積し続けず制限後に復帰 |
| 欠測と復帰 | 20／60／100／500 ms欠測、低品質、復帰時0.3 m移動済み | 無効化時点で積分停止。従来操縦へ移行し、古い位置へ跳ね戻らない |
| 離着陸・選択 | 高さ0.1→0.5→0.1 m、Stab／Sport、Auto／Manual切替 | 有効化・解除・初期化が仕様どおり。Yaw・高度指令を保つ |

すべての状態／遷移を網羅する。速度・加速度・合成傾きの上限は許容誤差内で成立し、非有限の出力がない。角度の連続性と定めた変化率上限を検証する。

## 3. 統合・機体モデルMIL

小角度水平運動 `aForward≈−g·Pitch`、`aRight≈g·Roll` に既存姿勢ループの遅延・応答、フロー量子化、ToF遅延、一定外乱を加える。単純な運動学だけで飛行成立と判断せず、利用可能な機体モデルでは姿勢・高度・配分の連成も含める。

外側ループは内側姿勢ループより十分遅く調整する。速度の減速が成立してから位置Pを有効にする。速度推定遅延0～100 ms、倍率±20%、時刻揺れ、推定Yawのずれ、低品質床、測距誤差、一定水平外乱、電池・推力余裕の低下を組み合わせて振動・発散・飽和を調べる。

制御OFFでは同じ再生入力に対し、既存モーター出力・姿勢／高度目標・Supervisorの動作が一致することを確認する。ログの拡張差分は別に確認する。

## 4. SIL／PIL・実機机上

固定サイズsingleの推定・目標生成・PIと生成コードを同じ入力で比較する。推定の数値誤差目標1e-4 m／m/s、角度1e-5 rad。累積誤差や状態差がある場合は根拠を調べ、許容差を無条件に緩めない。PIL対応が使えない場合は、同じ演算の実機再生・USB観測で補い、その範囲を記録する。

バッテリー・プロペラを外した机上確認で、待機PWMゼロ、リセット、時刻・有効性、ログ、モード選択、欠測時の出力を確認する。400 Hzの平均だけでなく最大と超過回数、50 Hz実行回の負荷、欠落数を測る。

現行版の記録は最大2,561 µs／予算2,500 µs、6,000周期中3回超過、周期欠落0。追加後は少なくとも60秒・24,000周期で欠落0を確認し、2.5 ms超過が残る場合は観測／集計と実行の配分を再検討する。制御・ログ無効の軽い条件だけで判定しない。

## 5. 段階的な飛行試験

| 段階 | 実験 | 初期目標・評価 |
|---|---|---|
| 推定のみ | 現行操縦で短いホバリング・低速移動・Yaw | 動画・床目印と速度／位置の方向・倍率を比較 |
| 速度制御 | 0.5 m高度、0.3 m/s以下の移動と中立 | 中立後1.5秒以内に0.08 m/s以下、追加移動0.25 m以内を目標 |
| 位置保持 | 初期位置で20秒、移動後の位置で20秒 | 実位置の半径0.2 m以内を目標。推定位置が動かないだけでは合格にしない |
| 操作の両立 | 前後・左右・対角、移動中Yaw、中立Yaw | 移動に逆らわず、離陸地点へ勝手に戻らず、新しい停止位置を保持 |
| 着陸・条件変化 | 同じ床で下降、補助OFF、品質低下の範囲を段階的に評価 | 低高度解除・手動移行・復帰が予測可能。制御とセンサー有効性をログで確認 |

同じ位置・速度だけでなく、補助状態、測定時刻、品質、角速度積分、ToF、目標、実角度、PI積分、配分飽和、処理時間を記録する。危険な欠測を実飛行で最初に作らず、MIL・机上で遷移を確認してから範囲を広げる。初期目標は未検証なので、結果に基づいて仕様と調整値を更新する。

現行Yawのまま短時間の水平試験を先に行い、機首の実旋回と推定方位のずれを外部観測でも記録する。時間変化する方位誤差が受け入れ目標を妨げる場合は、速度推定と負帰還の確認後、長い保持・移動の前に別段階のYaw補正へ進む。磁気校正・Yaw方位保持の試験は、その仕様を作る段階で追加する。
