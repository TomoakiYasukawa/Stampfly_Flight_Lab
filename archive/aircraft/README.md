# 過去の機体モデル

現在の実装モデルは、プロジェクト直下の `StampFly_IMU400.slx` です。
ここには基礎版、Flip を含む PID 比較版、公式制御版、机上・再生モデルを保管しています。
移動時のモデル内容は変更していません。元の場所と SHA-256 は [manifest.json](manifest.json) に記録しています。

これらを調べる場合は、MATLAB プロジェクトを開いてから対象のファイルを直接開いてください。
フォルダー全体を MATLAB パスに追加する必要はありません。
過去の機体モデルはそれぞれ設定が異なるため、現行の設定ガイドには使いません。
標準 Kalman Filter の比較版は [../kf400/](../kf400/) にあります。

PID比較版の保存済みコールバックは公式モデルを参照します。この版を開く場合は、先に同じフォルダーの `StampFly_Official_FlightTest400.slx` を開いてください。アーカイブしたモデルの内容は変更していません。
