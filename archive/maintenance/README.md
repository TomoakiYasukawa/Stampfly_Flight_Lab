# 過去版の構築・検証ツール

`scripts/`と`tools/`は過去のモデル移植・比較・展開を記録するための保守用です。現行モデルの通常利用には実行不要で、[セットアップ](../../docs/setup.md)のSimulinkメニューから設定・ビルド・書き込みを行います。

MATLAB側の過去版初期化関数を使う場合は、プロジェクトを開いて `configure_stampfly_archive` を実行します。これは保守スクリプトのパスだけを追加し、アーカイブのSLXフォルダーは検索パスへ追加しません。

モデル編集スクリプトはSimulink Agentic Toolkitを使用し、作成当時のブロックID・構造を前提にしています。移動後のパスは更新していますが、過去の構築手順全体を現在のモデルへ再実行することは検証していません。保存済みの比較モデル・検証結果を起点に読んでください。

書き込みツールは当時の開発機MAC・モデルのSHA-256・既存ファームウェアを照合する構成です。任意の購入機にそのまま使用するための手順ではありません。保存済みBIN・飛行結果は [firmware](../../firmware/README.md) と [履歴](../../docs/history/README.md)で識別します。
